# Asset Storage Policy

Heavy source and generated media are stored in Google Drive.

Drive project folder:
https://drive.google.com/drive/folders/14ZLWu5kRUHHC4ijQSRqLlKgAKGB7vWOc

Structure:
- `01_SOURCE_MEDIA/`: source/reference aircraft and weapons media.
- `02_GENERATED_MEDIA/`: generated graphics and working renders.
- `03_DELIVERABLES/`: final exports and packages.

GitHub keeps code, prompts, data/manifests and lightweight documentation. Do not add large binary media to Git; keep Drive references instead.
